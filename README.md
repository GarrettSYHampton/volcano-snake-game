# Volcano Snake Game

Free-to-play browser Snake game with a Volcano theme, shipped as a static site
with no backend. TypeScript + Vite + plain HTML5 Canvas, no game engine.

## Run

```sh
npm install
npm run dev
```

Then open the printed local URL (default http://localhost:5173) in a browser.

## Build

```sh
npm run build
```

Static output goes to `dist/`. Preview it with `npm run preview`.
